# Privacy

Codex Status Bar collects no data and has no servers. It runs entirely on your Mac. Its only network activity is a once-a-day update check: one request to GitHub's public API for the latest release tag, and one for the Homebrew cask file (also hosted on GitHub; it only matters once a cask exists), used only to show the update line in the menu. Nothing is sent to the developer (as with any update check or download, GitHub sees the request; the developer never does).
